# 模块索引

这份索引用于快速定位“哪个模块负责什么”。完整说明见 `docs/架构设计.md`。

## 执行入口

| 模块 | 负责功能 |
| --- | --- |
| `game_bot/scripted/runner.py` | 脚本入口；列出脚本、解析脚本名、准备默认窗口、运行脚本 |
| `game_bot/scripted/loop_script.py` | `loop_template` 主实现；读取 `state_scripts/*.yaml`，循环扫描模板并执行动作 |
| `game_bot/scripted/executor.py` | 普通 scripted 脚本执行器；封装 `ScriptExecutor` 和模板路径辅助方法 |

## loop_template

| 模块 | 负责功能 |
| --- | --- |
| `game_bot/scripted/loop_script.py` | 模板循环、模板元数据读取、动作执行、success/end/fallback 处理 |
| `game_bot/scripted/priority_match.py` | 按 `priority` 分组扫描模板并选择最佳命中 |
| `game_bot/scripted/runtime.py` | 脚本运行时封装；截图、匹配、点击、拖拽、按键、等待 |
| `game_bot/scripted/context.py` | `ScriptContext`，保存窗口、run id、截图路径、最近匹配和变量 |
| `state_scripts/*.yaml` | 可复用状态流程；`start_flows` 引用同名流程完成入口/恢复逻辑 |
| `game_bot/scripted/components/popups.py` | 通用弹窗恢复占位模块；业务入口不再使用 component |

## 模板与识别

| 模块 | 负责功能 |
| --- | --- |
| `game_bot/vision/template.py` | OpenCV 模板匹配核心实现 |
| `game_bot/vision/templates.py` | 模板分组、模板引用展开、模板列表管理 |
| `templates/icons/` | 模板图片目录；`loop_dirs` 基于这里查找 |
| `templates/icons/<group>/*.json` | 模板同名元数据，定义优先级、动作、点击区域和标记 |

## 窗口、截图、输入

| 模块 | 负责功能 |
| --- | --- |
| `game_bot/core/window.py` | 窗口查找、激活、移动、尺寸调整、置顶 |
| `game_bot/core/capture.py` | 窗口/桌面截图 |
| `game_bot/core/input.py` | 点击、拖拽、按键输入；必须走 dm.dll 后端 |
| `game_bot/core/dm.py` | `dm.dll` COM 包装 |
| `game_bot/core/models.py` | `Point`、`Rect`、`MatchResult`、`ActionResult` 等共享数据结构 |

## 配置与工作台

| 模块 | 负责功能 |
| --- | --- |
| `state_scripts/*.yaml` | `loop_template` 脚本配置 |
| `config/settings.yaml` | 游戏窗口标题、进程名、窗口尺寸等全局设置 |
| `config/popups.yaml` | 通用弹窗识别与恢复配置 |
| `game_bot/web/window_bridge.py` | 工作台本地 API；模板、截图、脚本、运行日志接口 |
| `frontend/src/App.vue` | Vue 工作台主界面；模板编辑、模板组、流程管理 |

## 快速判断

| 你要改什么 | 优先看哪里 |
| --- | --- |
| `loop_template` 每轮怎么选模板 | `game_bot/scripted/loop_script.py`、`game_bot/scripted/priority_match.py` |
| 模板命中后点击哪里 | 模板同名 JSON、`game_bot/scripted/runtime.py` |
| 模板动作支持哪些类型 | `game_bot/scripted/loop_script.py` 的 `_execute_template_actions()` |
| 连续无命中怎么恢复 | `game_bot/scripted/loop_script.py` 的 `_run_template_loop_script()` |
| 输入为什么没生效 | `game_bot/core/input.py`、`game_bot/core/dm.py` |
| 截图尺寸或窗口位置不对 | `config/settings.yaml`、`game_bot/core/window.py`、`game_bot/core/capture.py` |
| 工作台保存的模板字段 | `frontend/src/App.vue`、`game_bot/web/window_bridge.py` |
