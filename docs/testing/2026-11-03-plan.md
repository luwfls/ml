## 后端接口用例

共同前置：临时目录、独立 loopback 服务；每次 HTTP 请求记录必要入参、状态、响应、时间。测试产生的 ID 只用于关联证据，不含业务账号。无 SQL、sternLog、外部生产服务。

| ID/优先级 | 模块/入口 | 操作与独立预期 | 异步/恢复 |
| --- | --- | --- | --- |
| API-01/P0 | POST /api/tasks、/api/tasks/start | 两个保存流程按指定顺序执行；两个设备 PID 不同且均非服务 PID；每台完成两流程 | 最长 10 秒等待终态；停止服务清理 |
| API-02/P0 | /api/tasks/start、/api/flows、/api/tasks | 活动快照不随配置修改改变；同任务重复启动被拒；停止后使用新配置 | 有界状态等待，不重复不明写入 |
| API-03/P0 | /api/tasks/start | 忙碌/离线/未授权/未知设备逐项错误；坏设备失败不影响好设备成功 | 独立终态后清理 |
| API-04/P0 | /api/tasks/stop、GET /api/batches | 取消响应确认非 live；服务重启后历史和取消状态保留，重试产生新批次 | 有界等待、重启测试服务 |
| API-05/P0 | /api/debug/start、/api/debug/control | 步进起始 0 轮，next 后恰好 1 轮且保持；auto 继续；pause/resume/cancel 正确 | 仅设备替身 |
| API-06/P0 | /api/debug/start | 默认真实输入分支发出替身命令；dry_run=true 不新增输入命令 | 不操纵真实硬件 |
| API-07/P0 | /api/import、/api/states/save | 中文名称、生成 ID、裁剪尺寸正确；无效状态/保存失败不新增 State 或模板 | 测试级故障注入，不修改用户数据 |
| API-08/P0 | /api/flows、/api/flows/copy、/api/run | 空 State 可保存/复制/重开、ID 稳定；无效引用拒绝；空流程执行拒绝 | 临时目录清除 |
| API-09/P0 | /api/health、/api/preview、/api/crop | 真实 OCR 识别“确认收货”，多候选/模糊/图文 AND 命中；no-adb 服务拒绝设备输入 | CPU 本地模型，无模型下载 |
| API-10/P1 | /api/import、/api/crop | 错误 PNG、越界框返回 400；已有 State 集合不变 | 临时目录清除 |
